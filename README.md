# Algoritmos 2026.2

Repositório com todo o conteúdo produzido na disciplina de **Algoritmos** do curso de Análise e Desenvolvimento de Sistemas (ADS) — SPTech, semestre 2026.2.

Reúne os exercícios práticos de lógica de programação em JavaScript feitos em sala, cobrindo desde a introdução à linguagem até estruturas condicionais e escopo de variáveis, além do simulador desenvolvido no Projeto Integrador (PI).

## Estrutura do repositório

```
├── Introdução JS/
├── Introdução JS pt2/
├── Variavel Local/
├── Variavel Global/
├── If - Else/
├── If - Else pt2/
├── Else-If/
├── Atividade-Avaliativa/
│   └── Controle-de-Corridas.html
└── PI - Simulador/
    └── Calculadora-Silotech.html
```

### Descrição das pastas

- **Introdução JS / Introdução JS pt2** — primeiros exercícios com JavaScript: variáveis, entrada de dados, funções e manipulação de DOM (`alert`, `input`, `innerHTML`).
- **Variavel Local / Variavel Global** — exercícios sobre escopo de variáveis dentro e fora de funções.
- **If - Else / If - Else pt2** — estruturas condicionais simples, com exercícios de tomada de decisão (ex.: verificação de idade, altura, permissões).
- **Else-If** — estruturas condicionais encadeadas (`if / else if / else`).
- **Atividade-Avaliativa** — atividade avaliativa aplicando os conceitos de lógica em um cenário de controle de corridas.
- **PI - Simulador** — calculadora/simulador desenvolvido no Projeto Integrador, aplicado ao projeto **SiloTech** (estimativa de economia com monitoramento de silos).
