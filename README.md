## Descrição das sprints

### Sprint 1

Estudo de fundamentos de lógica e JavaScript:

- **introducao-js / introducao-js-pt2** — exercícios introdutórios com variáveis, entrada de dados, funções e manipulação do DOM.
- **variavel-local / variavel-global** — escopo de variáveis.
- **if-else / if-else-pt2 / else-if** — estruturas condicionais e tomada de decisão.
- **atividade-avaliativa** — exercício de simulação de uma viagem de carro.
- **pi-simulador** — calculadora financeira associada ao Projeto Integrador SiloTech.
- **exercicios-aula** — material complementar trabalhado em aula.

### Sprint 2

Prática de operadores lógicos, repetição e manipulação de textos e vetores:

- **while / while-2** — exercícios com laços de repetição.
- **and / or / and-e-or / or-mais-and** — operadores lógicos em condições.
- **string / operacoes-com-strings** — manipulação de textos.
- **vetor** — exercícios com arrays.
- **aula** — desafios e listas desenvolvidos durante as aulas.
- **pre-avaliativa / avaliativa** — atividades preparatórias e avaliativas.

## PI - Simulador

O SiloTech é o contexto do Projeto Integrador associado a este simulador financeiro, que considera cenários de monitoramento de silos. O simulador ajuda a estimar economias relacionadas à verificação manual de estoque, a eventos de transbordamento e a deslocamentos para visitas aos silos. Também calcula a economia mensal total, o payback do projeto e uma projeção anual com ROI, a partir dos valores informados pelo usuário.

O arquivo do simulador utiliza HTML5 e JavaScript.
