# Algoritmos 2026.2

Repositório com o conteúdo desenvolvido na disciplina de **Algoritmos** do curso de Análise e Desenvolvimento de Sistemas (ADS) — SPTech, semestre 2026.2.

## Descrição das sprints

### Sprint 1

Foco em fundamentos de lógica e JavaScript:

- **Introdução JS / Introdução JS pt2** — primeiros exercícios com variáveis, entrada de dados, funções e manipulação de DOM (`alert`, `input`, `innerHTML`).
- **Variavel Local / Variavel Global** — estudo de escopo de variáveis.
- **If - Else / If - Else pt2** — estruturas condicionais simples e exercícios de tomada de decisão.
- **Else-If** — desenvolvimento de lógica encadeada com `if / else if / else`.
- **Atividade-Avaliativa** — simulação de controle de corridas.
- **PI - Simulador** — calculadora/simulador do Projeto Integrador, aplicado ao projeto **SiloTech**.
- **exercicios-aula** — materiais e desafios complementares trabalhados em aula.

### Sprint 2

Foco em aprofundamento de operadores lógicos, repetição e manipulação de textos/vetores:

- **While / While-2** — exercícios com laços de repetição.
- **AND / OR / AND e OR / OR mais AND** — lógica booleana aplicada em condições compostas.
- **String / Operações com Strings** — manipulação de textos e métodos de string.
- **Vetor** — trabalho com arrays e estruturas de dados simples.
- **aula** — desafios e listas desenvolvidas durante as aulas.
- **pre-avaliativa / avaliativa** — atividades de preparação e avaliação final da sprint.
